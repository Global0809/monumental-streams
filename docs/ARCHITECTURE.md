# Monumental Streams — Architecture

```
content/        Authored JSON (one central catalogue, stable prefixed ids)      ← editors / future CMS import
  videos/*.json   one file per video (content-entry example: docs/CONTENT.md)
sources/        Raw media inputs (studio loops, archive films). Not served.
media/          Generated by scripts (never hand-edited)
  public/         previews, posters, captions, chapters, thumbnails  → served at /media/public/*
  protected/      HLS + MP4 renditions per media id                    → served at /stream/:mediaId/* (token-gated)
  manifest.json   measured media facts (duration, renditions, captions) — server-only paths
  art.json        art registry with lqip data URIs
shared/         Isomorphic TypeScript (runs in Node and the browser)
  types.ts        THE content + state contract
  schema.ts       zod validation of authored content
  catalogue.ts    normalised indexes (places hierarchy, setting overlap, programmes…)
  search.ts       full-text + combined filters + facets + relaxation suggestions
  url-state.ts    DiscoveryState ⇄ URLSearchParams
  relations.ts    explainable connections between any two entities
  recommend.ts    explainable recommendations from a Library + interests
  journey.ts      "Take Me Somewhere" planner (fits real runtimes into a time budget)
  library.ts      Library defaults + conflict-free merge (LWW per entry, tombstones)
server/         Express 5 on Node ≥22.18 (native TS type stripping, node:sqlite)
src/            React 19 client (Vite)
  styles/         tokens + base + component CSS (the biomechanical design system)
  systems/        cursor, sound, motion, heartbeat, previews, device capability
  state/          catalogue provider, personal library store (adapters), session/membership
  ui/             shared primitives (Pod, Chip, Button, Dialog, Badges, EmptyState…)
  features/       entry, home, catalogue, watch(player), programme, atlas, time, synapse,
                  somewhere, passport, you, membership, account, about
scripts/        media build, globe build, content check/add
tests/          unit (vitest) + e2e (playwright)
```

## Boundaries

| Concern | Owner | Notes |
|---|---|---|
| Content | `content/` + `shared/catalogue.ts` | Screens never copy catalogue text; they query the catalogue. |
| Playback | `src/features/watch/player/*` + `server/playback.ts` | Client asks `/api/playback/:id`; server checks entitlement and returns signed URLs. |
| Personal state | `src/state/library/*` | `LibraryAdapter` interface: `LocalAdapter` (guest, localStorage) and `ServerAdapter` (signed in, `/api/me/library`). Swap for any backend. |
| Auth | `server/auth.ts` | scrypt hashes, HttpOnly session cookie, CSRF double-submit + Origin check. |
| Membership | `server/billing.ts`, `server/entitlements.ts` | Stripe Checkout + verified webhooks when keys exist; otherwise `setup-pending` + clearly separated dev preview. |
| Audio | `src/systems/sound/*` | WebAudio synthesis, silent until explicit activation. |
| Motion | `src/systems/motion/*` | `data-motion` on `<html>`; system/reduce/full preference. |
| Spatial | `src/features/atlas/*` | Three.js globe lazy-loaded; SVG fallback; list alternative. |

## URL scheme (all direct-linkable and refresh-safe)

| Path | Purpose |
|---|---|
| `/` | Entry (skippable awakening on first visit only) + home |
| `/catalogue?q=&interest=&place=&period=&access=&dur=&prov=&playable=&sort=` | Search + combined filters |
| `/watch/:videoSlug?t=seconds` | Player + details + related/next |
| `/programme/:slug` | Series / chapter / campaign / demonstration series |
| `/collection/:slug` | Collection |
| `/atlas`, `/atlas/:placeSlug?route=:routeSlug&view=globe|map|list` | World discovery |
| `/time`, `/time/:periodSlug?lens=setting|published&movement=:slug` | Time machine |
| `/synapse/:kind/:slug` | Connection view for person / movement / theme / interest / video / place … |
| `/somewhere?interest=&minutes=&where=&mood=&seed=` | Take Me Somewhere instrument |
| `/passport`, `/passport?stops=a,b,c&title=` | Culture Passport journeys |
| `/you?tab=continue|saved|journeys|history|interests|settings|membership` | Your World |
| `/membership?checkout=success|cancelled` | Membership + upgrade journey |
| `/account?mode=signin|register` | Sign in / create account |
| `/about` | Platform, honesty notes, integration status |

## HTTP API

All JSON. Mutating requests require header `X-CSRF-Token` equal to the `ms_csrf` cookie and a same-origin `Origin`.

| Method & path | Result |
|---|---|
| `GET /api/health` | `{ ok: true }` |
| `GET /api/config` | `PlatformConfig` |
| `GET /api/catalogue` | `CataloguePayload` (ETag = version) |
| `GET /api/search?…same params as /catalogue` | `{ total, results: [{ id, score, matched }], facets }` |
| `GET /api/session` | `SessionInfo` (issues CSRF cookie) |
| `POST /api/auth/register {email,password,name}` | `SessionInfo` |
| `POST /api/auth/login {email,password}` | `SessionInfo` |
| `POST /api/auth/logout` | `SessionInfo` |
| `GET /api/me/library` | `{ library: Library \| null }` (401 when signed out) |
| `PUT /api/me/library {library}` | `{ library }` merged server-side with `mergeLibraries` |
| `POST /api/playback/:videoId` | `{ hls?, mp4, captions, chapters?, thumbnails?, expiresAt }` or `4xx { code }` where code ∈ `not_found, unavailable, premium_required` |
| `GET /stream/:mediaId/*?t=token` | Token-gated media (Range supported; playlists rewritten to carry the token) |
| `GET /media/public/*` | Public art, previews, captions, sprites |
| `POST /api/billing/checkout {plan}` | `{ url }` or `503 { code: 'billing_setup_pending' }` |
| `POST /api/billing/portal` | `{ url }` or `503` |
| `POST /api/billing/webhook` | Stripe-signed events only |
| `POST /api/dev/membership {status}` | Dev preview only (non-production + `DEV_PREVIEW_MEMBERSHIP=true`), signed in |
| `GET /api/activity` | `{ items: ActivityItem[], external: ExternalAvailability[] }` — maintained data only |

## Client contracts

* `useCatalogue()` → `Catalogue` (shared/catalogue.ts). Suspends until `/api/catalogue` resolves; cached in memory + `sessionStorage`.
* `useLibrary()` → `{ library, actions }` where actions = `setProgress, toggleSave, toggleSavePlace, saveJourney, removeJourney, recordHistory, clearHistory, toggleInterest, setPrefs, stamp`. Immediate local state; adapter persists.
* `useSession()` → `{ session, config, signIn, register, signOut, refresh }`.
* `sound.play(name)` where name ∈ `activate | select | hover | save | unsave | transition | tick | error | open | close | stamp`; `sound.duck(on)` while programmes play.
* `previews.request(el, src)` limits simultaneous preview loops (max 2 desktop / 1 mobile) and pauses when offscreen, hidden or during playback.
* Cursor: add `data-cursor="play|open|drag|save|text|hide"` and optional `data-cursor-label="Watch"` on elements; links/buttons default to `open`.
